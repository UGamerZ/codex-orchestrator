Автоматизированная работа с задачами через Codex


Подготовлена отдельная система для выполнения задач из Trello и проверки изменений перед передачей человеку. Для её запуска нужно завершить настройку сервера и подключить Trello и Telegram.

Новое

  • Выбор проекта. При установке можно подключить существующий репозиторий с нужного аккаунта GitHub или создать новый локальный проект. Локальная работа включает отдельные ветки и ревью без GitHub; при желании новый проект можно сразу опубликовать в приватном репозитории.
  • Очередь задач. Менеджер проверяет выделенную доску раз в час. Одновременно задачи могут выполнять два исполнителя.
  • Изменения на проверку. Каждая задача выполняется отдельно и передаётся в виде запроса на изменение проекта. После создания запроса карточка переходит в Done и остаётся там до ручного архивирования.
  • Проверка и исправление. Ревьюер проверяет результат и передаёт замечания исполнителю для автоматического исправления. Окончательное одобрение и объединение изменений остаются человеку.
  • Уточнения в Telegram. Если агенту не хватает условий задачи, данных или доступа, он приостанавливает работу и задаёт вопрос. Ответ на сообщение возвращается тому агенту, который его задал.
  • Уведомление о результате. Сообщение о выполненной задаче приходит после завершения проверки без замечаний.
  • Изолированная работа. Доступны два варианта установки: внутри Docker или в ограниченной среде Windows без виртуальной машины. Рабочие копии проекта размещаются отдельно. Агенты не получают доступы к управлению GitHub, Trello и Telegram.
