Automated task execution with Codex


A separate system handles Trello tasks and reviews changes before handing them to a person. Complete the server setup and connect Trello and Telegram before starting it.

New

  • Project selection. Connect an existing GitHub repository using an account with access, or create a new local project. Local development includes separate branches and reviews without GitHub. New projects can optionally be published to a private repository.
  • Task queue. The manager checks a dedicated board once an hour. Up to two executors can work at the same time.
  • Changes ready for review. Each task runs separately and produces a pull request or a local branch for review. The card moves to Done and stays there until someone archives it manually.
  • Review and fixes. The reviewer sends findings back to the executor for automatic fixes. Final approval and merging remain with a person.
  • Telegram questions. If an agent lacks clear requirements, data, or access, it pauses and asks a question. A reply returns to the agent that asked it.
  • Completion notifications. A task completion message is sent after review finishes without findings.
  • Isolated execution. Choose Docker or a restricted Windows environment without a virtual machine. Project working copies are separate, and agents do not receive GitHub, Trello, or Telegram management credentials.
  • English by default. The README, setup guides, system instructions, and operator messages use English. Russian documentation is available as a separate translation.
